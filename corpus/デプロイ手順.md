# デプロイ手順

架空のサービス「ノートポータル」の本番デプロイ手順。実験用に書いたもので、実在のサービスではない。

## デプロイ前の確認

- ステージングで直近のマイグレーションが通っていること
- 変更に DB のマイグレーションが含まれるなら、バックアップが 24 時間以内に取れていること
- 監視のアラートが静かであること（直前に別の障害が出ていないか）
- リリースノートに「戻し方」が書いてあること

## 手順

1. `main` にタグを打つ（`v` + 日付、例 `v20260512`）
2. イメージをビルドして、コンテナを入れ替える
3. ヘルスチェックが 3 回連続で通るまで待つ
4. トップページと検索を手で 1 回ずつ叩く

## ロールバック

直前のタグでイメージをビルドし直して入れ替える。DB のマイグレーションを戻す必要があるときは、
バックアップから復元する方が早い。ロールバックしたら、理由をリリースノートに追記する。
